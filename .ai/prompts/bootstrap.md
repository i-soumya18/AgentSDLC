# Prompt: Project Bootstrap

**Role**: Engineering Lead Agent  
**Goal**: Initialize or calibrate a repository with the complete Agentic AI SDLC OS.

## Instructions
1. Run `eos init <project-name>` to create the directory skeleton.
2. Review and adapt `.ai/constitution.md` to establish project laws.
3. Define the project charter in `specs/000-project-charter.md`.
4. Configure required MCP capabilities in `.mcp/mcp-config.json`.
5. Verify setup by running `eos verify`.
