# User Personas

## 1. Lead Architect / Solo Operator
- **Profile**: Experienced engineer acting as architect and reviewer for multiple simultaneous AI agents.
- **Pain Point**: Overwhelmed by reviewing random unverified code; needs high-level control via specs, ADRs, and gates.
- **Value Realized**: Operates as a software factory manager with full confidence in machine-verified evidence.

## 2. Autonomous Coding Agent (Claude Code / Copilot / Codex / Antigravity)
- **Profile**: AI software engineering agent executing coding and reasoning tasks.
- **Pain Point**: Lacks durable context across session resets; prone to hallucinating interfaces and expanding scope unbidden.
- **Value Realized**: Clear instruction hierarchy (`AGENTS.md` -> Constitution -> Spec -> Tasks), clear boundaries, and immediate feedback via gates.
