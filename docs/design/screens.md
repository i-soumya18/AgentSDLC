# Screen Inventory & Responsive Breakpoints

## Screen List
1. **Pipeline Dashboard**: Overview of features, active stages, and gate pass/fail icons.
2. **Specification Editor & Viewer**: Formatted view of `spec.md` with interactive checklist.
3. **Architecture & ADR Explorer**: Visual C4 diagram viewer and searchable ADR library.
4. **Gate Auditing & Evidence Log**: Detailed verification report with test outputs and eval scorecards.

## Breakpoint Rules
- **Mobile (< 768px)**: Single-column stacked cards; drawer navigation; full-width buttons.
- **Tablet (768px - 1024px)**: 2-column grid; collapsable sidebar.
- **Desktop (> 1024px)**: Persistent left sidebar, multi-column feature board, detailed side-by-side spec & code viewer.
