# Standard Error Model (RFC 7807 Problem Details)

All 4xx and 5xx API responses must strictly conform to RFC 7807 problem details:

```json
{
  "type": "https://api.example.com/errors/validation-error",
  "title": "Invalid Request Parameters",
  "status": 400,
  "detail": "The 'title' field must be between 1 and 255 characters.",
  "instance": "/api/v1/tasks",
  "invalidParams": [
    {
      "name": "title",
      "reason": "must not be blank"
    }
  ],
  "requestId": "req_01j7x8a92m",
  "timestamp": "2026-09-11T00:15:30Z"
}
```

### Fields Specification
- `type` (URI): Stable URI identifier for the error type.
- `title` (string): Short, human-readable summary of problem type.
- `status` (integer): HTTP status code generated by origin server.
- `detail` (string): Human-readable explanation specific to this occurrence.
- `instance` (string): Relative URI reference identifying the specific occurrence.
- `requestId` (string): Distributed tracing correlation identifier.
